# Module 3.5 — Servo Control via PWM (ESP32-S3)

Керування сервоприводом **SG90** за допомогою потенціометра на мікроконтролері **ESP32-S3** (фреймворк **ESP-IDF** у **PlatformIO**): масштабування у пропорції **1:1**, обрізання розбіжності діапазонів і логування кута відхилення від крайнього лівого положення в консоль.

## Схема підключення

| Компонент / вивід | ESP32-S3 / живлення | Примітка |
| :--- | :--- | :--- |
| Потенціометр — лівий край | `GND` | Крайнє ліве положення (`0°` потенціометра) |
| Потенціометр — середній (wiper) | `GPIO4` (`ADC1_CH3`) | Аналоговий вхід (макс. `3.3 В`, `ADC_ATTEN_DB_12`) |
| Потенціометр — правий край | `3V3` | Строго `3.3 В` (не `5 В`) |
| Сервопривод SG90 — сигнал (помаранчевий) | `GPIO5` (`LEDC CH0`) | ШІМ `50 Гц` (період `20 мс`), 14-бітна розрядність |
| Сервопривод SG90 — живлення (червоний) | `5V` (шини живлення) | Паралельно електролітичний конденсатор `100 мкФ`, `16 В` |
| Сервопривод SG90 — земля (коричневий) | `GND` | Спільна земля контролера, потенціометра та серво |

## Логіка 1:1 та обрізання діапазону

Фізичний кут повороту потенціометра становить $0^\circ\text{–}270^\circ$ (`POT_MAX_ANGLE_DEG`), а робочий хід сервоприводу SG90 — $0^\circ\text{–}180^\circ$ (`SERVO_MAX_ANGLE_DEG`).

1. Значення АЦП з `ADC1_CH3` усереднюється по 16 вибірках і переводиться у кут повороту потенціометра від крайнього лівого положення:
   $$\theta_{\text{pot}} = \frac{\text{ADC}_{\text{avg}}}{4095} \times 270^\circ$$
2. Для збереження пропорції **1:1** кут сервоприводу обрізається за межами робочого діапазону сервоприводу:
   $$\theta_{\text{servo}} = \operatorname{clamp}(\theta_{\text{pot}},\, 0^\circ,\, 180^\circ)$$
3. У діапазоні $0^\circ\text{–}180^\circ$ вал сервоприводу повторює кут потенціометра **1:1**. Понад $180^\circ$ сервопривод утримується на $180^\circ$, а в консоль виводиться позначка `[CLIPPED]`.
4. Щоб уникнути тремтіння від шумів АЦП і зайвого спаму в лог, застосовано мертву зону `1.0°` для сервоприводу та крок `5.0°` для логування потенціометра в зоні обрізки.
